# iPhone-Checkliste für Tagzeiten

Was sich nur auf einem echten Gerät prüfen lässt. Dauer: etwa 20 Minuten, verteilt auf einen Tag.
Voraussetzung: Die App ist über HTTPS erreichbar (z. B. GitHub Pages, Netlify, eigener Server) und
der Server leitet unbekannte Pfade auf `index.html` um.

## 1. Installieren

- [ ] In **Safari** öffnen (nicht in einer anderen App), Teilen-Knopf → **„Zum Home-Bildschirm“**.
- [ ] Symbol auf dem Home-Bildschirm: Lutherrose auf dunklem Grund, Name „Tagzeiten“.
- [ ] Vom Home-Bildschirm starten: keine Safari-Leiste, die App füllt den Bildschirm.

## 2. Ränder (Notch, Home-Leiste)

- [ ] Kopfzeile „Tagzeiten“ und Datum liegen unter der Statusleiste, nicht dahinter.
- [ ] Untere Leiste (Heute … Mehr) liegt über der Home-Leiste, alle sechs Bereiche lassen sich antippen.
- [ ] Morgen → „Zeit starten“, dann nach unten scrollen: Der Timer bleibt oben stehen und deckt die
      Statusleiste sauber ab, ohne dass Text dahinter durchscheint.
- [ ] Katechismus → Hausvater-Modus: „Hausvater-Modus beenden“ und „Nächstes Stück“ sind erreichbar.
- [ ] Querformat: nichts wird vom Notch verdeckt.

## 3. Offline

- [ ] App einmal mit Netz öffnen und alle sechs Bereiche antippen.
- [ ] Flugmodus einschalten, App ganz schließen (nach oben wischen), neu starten.
- [ ] Alle Bereiche öffnen sich, Schrift sieht aus wie mit Netz (Literata für Texte).
- [ ] Einen Eintrag machen (z. B. Dank im Nachtgebet), App schließen, wieder öffnen: der Eintrag ist da.

## 4. Ein ganzer Tag ohne Tastatur

- [ ] Morgens: Am Bett → „Am Bett gebetet“, dann alle sechs Schritte mit „Weiter zu: …“ bis
      „Stille Zeit abschließen“. Der Bildschirm bleibt an, solange der Timer läuft.
- [ ] Lesung: Links öffnen bibleserver.com, „Heute gelesen“ rückt die Lesung weiter.
- [ ] Abends: „Vesper abschließen“; im Nachtgebet die Rückschau mit + ~ – setzen, bei ~ oder –
      „Morgen wieder“ wählen, dann „Tag abschließen“.
- [ ] Am nächsten Morgen unter „Die Ausrichtung“ erscheint das Ding als Vorschlag.

## 5. Eingaben

- [ ] Beim Tippen in ein Feld zoomt Safari nicht hinein.
- [ ] Etwas tippen und die App sofort schließen (nach oben wischen): Beim nächsten Start ist es da.
- [ ] Die Tastatur verdeckt das aktive Feld nicht dauerhaft.

## 6. Dunkles Farbschema um 04:00

- [ ] iPhone auf Dunkel (oder in der App: Mehr → Darstellung → Dunkel).
- [ ] Nichts blendet: kein reines Weiß, rote Rubriken gut lesbar, grüne „gebetet“-Markierungen erkennbar.

## 7. Daten

- [ ] Mehr → „Sicherung exportieren (JSON)“: Datei landet in „Dateien“ oder im Teilen-Dialog.
- [ ] Mehr → „Als Text exportieren (Markdown)“: Datei lässt sich öffnen und lesen.
- [ ] Sicherung auf einem zweiten Gerät (oder nach „Alles löschen“) einspielen: alle Tage sind wieder da.

## 8. Neue Version

- [ ] Nach einer Veröffentlichung erscheint in der App „Eine neue Version der App ist bereit.“ –
      die App lädt sich nicht von selbst neu. „Jetzt aktualisieren“ lädt die neue Version.

Wenn etwas nicht stimmt: Bildschirmfoto machen und kurz notieren, bei welchem Punkt.
